# Своя тропа

Игра для платформы «Своё за городом». Сезон на карте России собирает тур, ночь и дорогу в одну заявку конструктора путешествий.

Это решение задачи 3 стипендиальной программы РСХБ 2026–2027: игра о путешествиях по России, которую можно встроить в платформу и связать с картой, маршрутами, отелями и транспортом.

Прототип не является сайтом банка и не офертой. Цены учебные.

## Как открыть

```bash
npm install
npm run dev
```

Сервер: [http://127.0.0.1:47231](http://127.0.0.1:47231)

В журнале на экране есть цель, правила и сценарии. Кнопки «Собрать ближние выходные» и «Собрать две тропы» заполняют маршрут для просмотра чека.

## Что приложить к заявке

Форма на сайте программы просит три вещи.

1. **Опишите ваши достижения.** Короткое поле про вас, не про кейс. Допишите сами курс, вуз и один свой проект. Готовую биографию подставлять неоткуда.
2. **Решение кейсового задания.** Загрузите файл `submission/svoya-tropa-reshenie.pdf`. В нём цель, правила, сценарии, связь с бронью и снимки прототипа. Лимит формы — 20 МБ.
3. **Ссылка на решение.** Публичный адрес прототипа. Локальный адрес жюри не откроет: опубликуйте проект и вставьте полученную ссылку.

Журнал внутри игры дублирует текст решения, если файл не откроется.
